Tip Use two browsers/devices. Flow: A: Create Offer → Copy → send to B → B: Set Remote & Create Answer → Copy → send to A → A: Paste & Set Remote
Single file • No deps

What’s happening?

  1. You generate an SDP “offer” that includes ICE candidates.
  2. Your peer sets that as remote, then generates an “answer.”
  3. You set their answer as your remote. When the data channel opens, you’re connected.

If it won’t connect, try toggling STUN, or use the same network/VPN. Some strict NATs need a TURN server (not included here).
